# Stancel

**ES** · Escritorio de operativa para MetaTrader 5. Vigila el límite de pérdida
diaria que tú fijas y, cuando se alcanza, cierra las posiciones y bloquea el
envío de órdenes. No da señales y no promete resultados.

Sale el 19 de enero de 2027. Web: https://stancel.net/

**EN** · A trading desk for MetaTrader 5. It watches the daily loss limit you
set and, when it is reached, closes positions and blocks new orders. It gives no
signals and promises no results.

Launching 19 January 2027. Web: https://stancel.net/en/

Stancel Tempo, the free session and calendar strip for MT5, is on the MQL5 Market.
